# 期末保卫战

以校园棋子为主题的 2D 塔防游戏。当前版本围绕战斗提供可游玩的 28 天流程：选择阵容、部署与升级、结算、购买补给，再进入下一天。

**当前状态：额外的 UI 改动已清理，但页面最终验收暂停。** 用户提供了另一位开发人员已实现的手绘四按钮主菜单截图；本仓库 `origin/main` 重新拉取后仍为2026-07-30的 `30b6d962`，没有那套页面资源。需取得对应提交或工程后接回正确页面；恢复仓库旧布局不等于已对齐该截图。当前源码尚未完成这次调整后的完整 Unity 流程与 Mac 构建验证，旧构建和旧报告均不能作为本次完成证明。

## 启动

### Unity 编辑器

1. 使用 **Unity 6000.5.1f1** 打开本项目，等待资源导入完成。
2. 打开 [MainMenu 场景](Assets/_Game/Scenes/MainMenu.unity)，点击 Play。
3. 选择新游戏，完成人格问答后继续；已有本地进度可从主菜单继续。

### Mac 成品

Mac 构建输出路径为 **`Builds/Mac/FinalDefense.app`**，构建完成后可直接打开。
`Builds/` 不纳入版本控制；本地没有成品时，按[发布验证与构建说明](Tools/VERIFY_RELEASE.md)生成。

## 一局怎么玩

六个页面组成完整循环：

**主菜单 → 人格问答 → 主菜单 → 日程 → 战斗 → 结算 → 商店 → 下一天日程**

第 28 天结束后进入期末总结。GPA 耗尽会提前结束本轮游戏，可从终局或主菜单开始新游戏。

- **编队**：战前从 16 种棋子中选择 8 种；敌方使用剩余 8 种对应的敌人技能版本。开始前可以调整阵容。
- **部署**：拖动卡牌到合法格子，或先点击卡牌再点击格子。地面与高台棋子各有可部署区域。
- **朝向**：部署时按 **R** 切换朝向，查看箭头和射程预览。
- **暂停**：按 **Space** 或点击开始／暂停按钮；**Esc** 打开菜单。
- **升级**：点击已部署棋子，再点升级，消耗 COST；最高 Lv.3。
- **倒地**：棋子倒地后等待 **15 秒**，再选择它并点击重新部署，支付部署 COST，等级重置为 Lv.1。
- **补给**：每个新对局自动从库存中携带每类道具 1 件；同类效果只生效一次。同一天重试保留携带效果，不重复扣库存。
- **重试**：失败后当天首次重试免费，之后每次消耗 5 GPA；胜利后进入结算与商店。

战斗开始后，主动重新挑战、返回主菜单或正常关闭 Mac 成品窗口都会按**弃局**结算；开始前离开不算弃局。本地存档保存流程、阵容与库存，异常中断恢复准备检查点，不恢复战斗中的单位位置。

## 战术提示

- 用能阻挡多个敌人的棋子守路口，让输出和治疗的射程覆盖它；注意部署朝向。
- 前期把 COST 分配给第二个阻挡点和多个输出单位，避免只升级少数棋子。
- 留意倒地棋子的冷却。及时支付 COST 重新部署，往往比继续升级后排更能防止漏怪。

## 当前内容与范围

- 16 种我方棋子及对应的 16 种敌人技能，包含灼烧、中毒、控制、盾反、追击和治疗等战斗机制。
- 12 种战斗补给效果，连接库存、商店、胜利掉落、本地存档与结算。
- 已导入提供的 **45 张原素材**：16 张棋子、10 张角色图、19 张道具图标。棋子和道具图片用于原页面中的对应控件；角色图保留为资源，不新增整页立绘。来源与裁剪记录见素材清单。
- 页面沿用仓库 `30b6d962` 的主题与布局，撤除后来新增的纸张配色、大立绘和战斗分栏；战斗功能接入原场景控件。
- 已接入提供的 **3 首 BGM**，按主菜单／商店、人格问答、日程／战斗切换，支持循环与淡入淡出；见[音乐说明](Docs/Audio/README.md)。
- **28 天目前复用 Level1 地图及 4 波、41 敌的数量和时间轴**；编队会改变敌方身份与技能组合。当前没有 28 个独立设计的关卡。
- 功能集中在战斗及其前后流程。AVG 剧情、NPC 对话、AI 选人服务与独特的 28 关内容尚未完成。
